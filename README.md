# 异构服务器选型配置与算力匹配测算平台 V1.0

面向采购服务器与算力资源的企业 IT、系统集成商与算力项目方的 H5 在线工具：录入业务负载类型、并发规模、算力需求与预算区间，自动比对多品牌异构服务器机型参数库，输出算力匹配度、Top3 配置组合与性价比排序，生成可下载 PDF 的选型测算报告。

## 在线演示（GitHub Pages 静态版）

- **演示地址**：<https://yeqifang0.github.io/heterogeneous-server-selection-platform/>
- 无需服务器即可访问：`docs/` 目录为静态演示版，测算引擎、评分排序与六章报告组装均在浏览器端运行（与 `server/src/calc.js`、`report.js` 同源逻辑，同一输入结果一致）
- 静态演示版中，注册账号、测算任务与订单保存在浏览器 localStorage；PDF 导出通过报告页「打印 / 另存为 PDF」实现
- 完整版（Node.js 后端，服务端计算 + PDFKit 矢量 PDF）见本仓库 `server/` 目录

## 技术栈

- **前端**：HTML5 / CSS3 / 原生 JavaScript（哈希路由 SPA，零框架依赖，Canvas 柱状图自绘）
- **后端**：Node.js + Express（评分计算全部在服务端完成，前端仅展示）
- **报告导出**：PDFKit + Windows 黑体字体（simhei.ttf），矢量表格与柱状图
- **数据**：JSON 文件存储（机型库 / 规则表 / 用户 / 订单 / 任务），原子写入
- **认证**：scrypt 口令哈希 + 令牌会话

## 快速启动

### 方式一：启动脚本（Windows）

双击 `启动平台.bat`（自动定位本机 Node，本机已含便携版 Node v20.18.1 于 `C:\Users\admin\.nodejs`）。

```bash
cd server
npm install          # 首次运行；本机已安装完成可跳过
npm start            # 或 node src/index.js
```

启动后访问 **http://127.0.0.1:3000**

> 若本机未安装 Node：项目开发时已下载便携版到 `C:\Users\admin\.nodejs\node-v20.18.1-win-x64\`，
> 可用其下的 `npm.cmd install` / `node.exe src/index.js` 运行；生产环境建议安装 Node ≥ 18。

## 核心测算规则（全部后台可配置，前端不写死）

1. **负载画像映射**：7 类业务场景 → 计算密集 / IO 密集 / 混合 / GPU 密集
2. **容量换算**：每千并发 CPU 核数、每核内存、每千并发 GPU 卡数、存储系数、带宽系数 + 30% 性能余量
3. **机型筛选**：22 款多品牌异构机型（Intel / AMD / 鲲鹏 / 海光 × A800 / H800 / H100 / 昇腾 910B / 深算 DCU / RTX），预算区间 + 交付周期约束，逐级放宽并明确提示
4. **加权评分**：性能匹配 40% + 性价比 30% + 功耗 15% + 维保供货 15%（权重在后台规则表可调，和必须为 1）
5. **输出**：Top3 推荐配置 + 1 套备选 + 性价比排序（算力/万元指数）

规则表位于 `server/data/rules.json`，也可经管理后台在线维护（换算系数、权重、收费标准、报告模板文案、电价/PUE）。

## 报告结构（六章 + 附录）

一、需求摘要 → 二、负载画像分析（含换算依据） → 三、推荐配置方案（机型/CPU/GPU/内存/存储/网络/单价/总价/适配度/推荐理由） → 适配度柱状对比图 → 四、多机型横向对比矩阵 → 五、性价比排序与选型建议 → 六、风险与注意事项（余量/扩容/功耗电费/供货/合规） → 附：参数假设与免责声明

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bootstrap` | 选项 / 定价 / 权重（前端渲染依据） |
| POST | `/api/tasks` | 提交测算（后端二次校验） |
| GET | `/api/tasks/:id/summary` | 脱敏摘要（免费） |
| GET | `/api/tasks/:id/calc` | 完整测算结果（购快速测算或报告） |
| GET | `/api/tasks/:id/report` | 六章报告（购正式报告） |
| GET | `/api/tasks/:id/report.pdf` | PDF 下载（购正式报告） |
| POST | `/api/orders` · `/api/orders/:id/pay` | 下单 / 支付确认 |
| * | `/api/admin/*` | 机型 CRUD / 规则维护 / 订单 / 统计（管理员） |

## 合规边界

本平台仅输出配置选型与测算建议，不提供现场部署、上架布线、整机安装调试等服务；报告为选型辅助，不构成采购承诺，最终采购决策由用户自行判断。机型参数与单价来源于公开资料整理，实际以厂商正式报价为准。
